OBYWATEL AI — INFORMACJA DLA JURY
================================

1. OTWARCIE PROTOTYPU

Prototyp działa w przeglądarce i nie wymaga instalacji ani logowania.

Link:
https://mobywatel-asystent-formalnosci.onrender.com/aplikacja

Aplikacja jest hostowana na Renderze. Jeśli bezpłatna instancja była
nieaktywna, Render uruchomi ją automatycznie po wejściu na stronę. Pierwsze
ładowanie po przerwie może potrwać dłużej — prosimy poczekać, aż strona się
wyświetli. Nie trzeba ręcznie uruchamiać serwera.

2. JAK SPRAWDZIĆ FUNKCJE

Asystent Formalności

1. Na ekranie głównym otwórz „Asystent Formalności”.
2. Wybierz „Zaplanuj swoje formalności”.
3. Wybierz sytuację, np. przeprowadzkę, zakup samochodu albo rozpoczęcie
   pierwszej pracy. Odpowiedz na krótkie pytania dopasowane do tej sprawy.
4. Przejrzyj plan, szczegóły kroków i oficjalne źródła. Zaznacz wykonane
   zadanie, aby zobaczyć zmianę postępu.
5. Plan trafia do „Moich spraw” dopiero po wybraniu przycisku dodania go do
   planów.
6. Możesz też wybrać „Inna sprawa” i opisać potrzebną formalność urzędową.

Wyjaśnianie pism

1. W Asystencie otwórz „Wyjaśnij pismo urzędowe”.
2. Wybierz „Wstaw pismo demonstracyjne”, aby zobaczyć przykładowy scenariusz
   bez dodawania własnego pliku. Można też dodać PDF lub zdjęcie albo wkleić
   treść.
3. Sprawdź podsumowanie, wykryte czynności i terminy. Możesz wyjaśnić
   wskazany fragment, zadać pytanie o pismo i zaproponować dodanie czynności
   do sprawy.
4. Dodane pisma można ponownie otworzyć w „Moich sprawach”.

W „Moich sprawach” można przeglądać plany, zadania i analizowane pisma,
śledzić postęp oraz usuwać zapisane pozycje. Dane prototypu są przechowywane
lokalnie w przeglądarce i nie wymagają konta użytkownika.

3. MODEL AI I TRYB DEMONSTRACYJNY

Do integracji z polskim modelem Bielik 11B v3 wykorzystano zgodne z API
OpenAI API platformy Fabryka AI:
https://fabryka.ai/platform

Nie wykupiono płatnego dostępu do Bielika. Integracja korzysta z limitu Free
API dostępnego na koncie Fabryka AI. Zgodnie z aktualną ofertą Free API
obejmuje 10 generacji dziennie; licznik odnawia się o 00:00 UTC (w Polsce
zimą o 01:00, latem o 02:00). Dostępność może zależeć także od obciążenia
usługi. Aktualne informacje:
https://fabryka.ai/regulamin.html

Po wyczerpaniu limitu lub przy niedostępności dostawcy aplikacja przechodzi
na odpowiedzi demonstracyjne. Są one wyraźnie oznaczone. W planowaniu spraw
jest to szkic bazujący na lokalnych kopiach oficjalnych kart usług; przy
analizie pism przykład jest fikcyjny i nie opisuje przesłanego dokumentu.
Taki wynik nie jest przedstawiany jako analiza wykonana przez AI. Wbudowane
pismo demonstracyjne służy do przejścia całej ścieżki bez wykorzystania
własnego dokumentu.

Publiczny prototyp jest przeznaczony do demonstracji. Prosimy nie dodawać
prawdziwych pism ani danych osobowych. Informacje z planu należy sprawdzić
w podlinkowanym źródle urzędowym.

4. TECHNOLOGIE I STRUKTURA PROJEKTU

- Python — serwer HTTP, API aplikacji oraz komunikacja z modelem.
- HTML, CSS i JavaScript — interfejs aplikacji w przeglądarce.
- Bielik 11B v3 przez Fabryka AI — opcjonalne generowanie planów i analiza
  treści, zależnie od dostępności limitu API.
- Lokalna wyszukiwarka BM25 i kopie kart usług Gov.pl — wyszukiwanie
  oficjalnych źródeł do planów.
- PyMuPDF, Pillow, pytesseract i Tesseract OCR — odczyt PDF-ów oraz zdjęć.
- localStorage i IndexedDB — zapis postępu, spraw i źródeł dokumentów
  w przeglądarce.
- Docker i Render — konteneryzacja oraz publiczne wdrożenie.

Najważniejsze pliki:

mockup/index.html
  Główna strona prototypu.

mockup/style.css
  Style i układ interfejsu.

mockup/formalnosci.js
  Nawigacja Asystenta Formalności, pytania, plany, postęp spraw, tłumacz
  pism, tryb demonstracyjny i zapis w przeglądarce.

serwer/server.py
  Serwer i endpointy API, integracja z modelem, odczyt dokumentów oraz
  obsługa odpowiedzi demonstracyjnych.

serwer/wiedza.py oraz serwer/wiedza/
  Wyszukiwarka i lokalne kopie materiałów źródłowych usług publicznych.

Dockerfile, requirements-doc-ai.txt, render.yaml
  Konfiguracja kontenera, zależności do analizy dokumentów i wdrożenie
  na Renderze.

tests/test_formalnosci.py
  Testy regresji kluczowych zachowań Asystenta Formalności.

5. CHARAKTER PROTOTYPU

Obywatel AI jest niezależnym prototypem konkursowym. Nie jest oficjalną
usługą administracji publicznej ani aplikacją mObywatel i nie łączy się
z rejestrami państwowymi. Nie podejmuje decyzji administracyjnych. Lokalna
baza kart usług może nie odzwierciedlać najnowszych zmian, dlatego przed
wykonaniem formalności należy sprawdzić podlinkowane źródło urzędowe.
