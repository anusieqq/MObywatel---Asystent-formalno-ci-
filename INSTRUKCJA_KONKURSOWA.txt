OBYWATEL AI — INSTRUKCJA URUCHOMIENIA I MATERIAŁY DO ZGŁOSZENIA
================================================================

1. OPIS PROJEKTU DO FORMULARZA KONKURSOWEGO

Obywatel AI to klikalny prototyp asystenta, który porządkuje formalności w
czytelne kroki. Użytkownik może przygotować plan dla wybranej sytuacji,
monitorować jego postęp, zadać pytanie o sprawę oraz skorzystać z tłumacza
pism urzędowych. W przykładowym trybie system jasno oznacza treści
demonstracyjne; po skonfigurowaniu API może analizować dokumenty i tworzyć
plany na podstawie oficjalnych kart usług.

Prototyp nie jest usługą administracji publicznej, nie jest oficjalną
aplikacją mObywatel i nie łączy się z rejestrami państwowymi. Przykładowe
dane i pismo demonstracyjne są fikcyjne.


2. LINK DO KLIKALNEGO PROTOTYPU

Adres lokalny do testów: http://127.0.0.1:8790/aplikacja

Adres lokalny działa wyłącznie na komputerze, na którym uruchomiono serwer.
Publiczny prototyp konkursowy (HTTPS, bez logowania):
https://mobywatel-asystent-formalnosci.onrender.com/aplikacja

Projekt zawiera plik render.yaml przygotowujący wdrożenie kontenerowe na

Hosting działa na Renderze. Konto Hobby kosztuje 0 USD miesięcznie, natomiast
koszt obliczeń zależy od typu instancji przypisanego do usługi. Przy instancji
Free hosting usługi kosztuje 0 USD. Darmowa instancja usypia się po 15 minutach
bez ruchu i automatycznie uruchamia po kolejnym wejściu. Pierwsze otwarcie po
przerwie może więc potrwać dłużej; nie trzeba ręcznie uruchamiać serwera.
Aktualne ceny i ograniczenia: https://render.com/pricing oraz
https://render.com/docs/free

Publiczny prototyp służy do demonstracji. Nie należy przesyłać do niego
prawdziwych pism ani danych osobowych.


3. DODATKOWY LINK — POLSKIE MODELE I TECHNOLOGIE

Model językowy: Bielik 11B v3 Instruct, model rozwijany przez SpeakLeash:
https://huggingface.co/speakleash/Bielik-11B-v3.0-Instruct

API do korzystania z modelu: Fabryka AI:
https://fabryka.ai/platform

Nie wykupiłam płatnego dostępu do Bielika ani płatnego pakietu API. Korzystam
z bezpłatnego limitu API dostępnego na koncie Fabryka AI. Po wykorzystaniu
limitu lub gdy dostawca AI jest chwilowo niedostępny, aplikacja przechodzi w
tryb demonstracyjny. W planach formalności pokazuje wtedy oznaczony szkic
oparty na lokalnych kopiach oficjalnych kart usług. Przy analizie pism
wyświetla fikcyjny przykład z wyraźną informacją, że nie jest to analiza
przesłanego dokumentu. Odpowiedzi demonstracyjne nie są przedstawiane jako
wynik działania AI.

Aplikacja obsługuje integrację z API Fabryka AI po stronie serwera. Klucz
API nie trafia do kodu przeglądarki ani repozytorium. W środowisku Render
ustawia się go jako tajną zmienną DOC_AI_API_KEY; adres API i model to
DOC_AI_BASE_URL=https://fabryka.ai/v1 oraz DOC_AI_MODEL=bielik-11b-v3.

Wykorzystane technologie:
- Python i biblioteka standardowa — serwer HTTP oraz API aplikacji;
- HTML, CSS i JavaScript — interfejs działający w przeglądarce;
- lokalna wyszukiwarka BM25 — dopasowanie spraw do kopii oficjalnych kart
  usług przechowywanych w katalogu serwer/wiedza/;
- Bielik przez Fabryka AI — opcjonalna analiza tekstu i planów po ustawieniu
  klucza API;
- PyMuPDF, Pillow i pytesseract — opcjonalny odczyt PDF-ów oraz OCR zdjęć;
- IndexedDB i localStorage — lokalny zapis postępu, spraw i kopii
  analizowanych dokumentów w przeglądarce;
- Docker — powtarzalne uruchamianie serwera i wdrożenie kontenerowe.


4. URUCHOMIENIE NA WINDOWS

Wymagany jest Python 3.9 lub nowszy. Otwórz PowerShell w katalogu głównym
projektu, czyli obok plików Dockerfile i README.md, a następnie uruchom:

    py -3 serwer\server.py

Jeśli polecenie py nie jest dostępne, użyj:

    python serwer\server.py

Otwórz w przeglądarce:

    http://127.0.0.1:8790/aplikacja

Serwer zatrzymasz skrótem Ctrl+C w oknie PowerShell.

Bez klucza API działają scenariusze demonstracyjne. Gdy lokalnie skonfigurujesz
klucz, aplikacja może wysyłać tekst do modelu. Jeśli limit API się wyczerpie
lub usługa AI będzie niedostępna, zobaczysz jawnie oznaczoną odpowiedź
demonstracyjną. Przy plikach, których nie da się odczytać (np. uszkodzonych
lub w nieobsługiwanym formacie), aplikacja nadal pokaże komunikat o błędzie
odczytu zamiast udawać analizę.


5. KONFIGURACJA BIELIKA (OPCJONALNA)

1. Skopiuj .env.example do pliku .env w katalogu głównym projektu.
2. Wstaw klucz API do DOC_AI_API_KEY.
3. Zachowaj ustawienia DOC_AI_BASE_URL=https://fabryka.ai/v1 oraz
   DOC_AI_MODEL=bielik-11b-v3 albo wpisz wartości dostępne na swoim koncie.
4. Uruchom ponownie serwer.

Na Renderze nie przesyłaj całego pliku .env. W panelu usługi otwórz
Environment i ustaw osobno DOC_AI_API_KEY, DOC_AI_BASE_URL i DOC_AI_MODEL.
Po zapisaniu wybierz Save and deploy (lub Save, rebuild, and deploy), aby
serwer uruchomił się z nowymi ustawieniami. Sekret należy zachować poza
repozytorium i materiałami konkursowymi.

Pliku .env nie wolno dołączać do zgłoszenia, repozytorium publicznego ani
archiwum dla jury. Jest ignorowany przez .gitignore. Nie wpisuj do prototypu
prawdziwych danych osobowych ani dokumentów zawierających takie dane.

Do odczytu plików PDF i zdjęć potrzebne są dodatkowe pakiety:

    python -m pip install -r requirements-doc-ai.txt

Do OCR skanów potrzebny jest również Tesseract OCR z językiem polskim.
Konfigurację ścieżki można ustawić zmiennymi TESSERACT_CMD i
TESSDATA_PREFIX. Zwykłe skopiowanie lub wklejenie tekstu pisma nie wymaga
OCR.


6. STRUKTURA NAJWAŻNIEJSZYCH PLIKÓW

mockup/index.html
  Główny dokument strony oraz punkty wejścia do sekcji aplikacji.

mockup/style.css
  Style aplikacji i komponentów Asystenta Formalności.

mockup/formalnosci.js
  Nawigacja zakładki, pytania dopasowane do sytuacji, plan i postęp spraw,
  tłumacz pism, obsługa wielu plików, wersje demonstracyjne oraz lokalny
  zapis danych przeglądarki.

serwer/server.py
  Serwer HTTP, endpoint analizy dokumentu i planowania, komunikacja z
  modelem, kontrola formatów oraz odczyt jednego lub kilku plików.

serwer/wiedza.py
  Lokalna wyszukiwarka kart usług administracji publicznej.

serwer/wiedza/
  Kopia danych źródłowych Gov.pl używana przez wyszukiwarkę. Zawartość może
  nie odzwierciedlać najnowszego stanu usług; przed działaniem należy
  otworzyć i sprawdzić oficjalną kartę.

.env.example
  Wzór ustawień. Nie zawiera klucza.

Dockerfile, docker-compose.yml
  Konfiguracja obrazu oraz lokalnego uruchomienia przez Docker.

render.yaml
  Konfiguracja wdrożenia aplikacji demonstracyjnej na Render bez klucza AI.


7. CO SPRAWDZIĆ PRZED WYSŁANIEM

- Wstawić publiczny adres HTTPS zamiast placeholdera w sekcji 2.
- Otworzyć link w oknie prywatnym i sprawdzić, czy nie wymaga logowania.
- Przejść scenariusz planu, oznaczyć krok i sprawdzić pasek postępu.
- Użyć przycisku „Wstaw pismo demonstracyjne” i przejrzeć odpowiedź.
- Potwierdzić, że w nagłówkach wyników demonstracyjnych nie ma informacji,
  jakoby analizę wykonało AI.
- Nie wysyłać do publicznej wersji klucza API ani prawdziwych dokumentów.
- Lokalnie uruchomić testy regresji poleceniem:

      python -m unittest discover -s tests -v
